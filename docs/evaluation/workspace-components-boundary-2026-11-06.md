## Component contract

ProjectsPage owns one fresh-access coordinator. Private collection discovery first checks the current principal over the network, then obtains a fresh, non-cache collection list using the captured credential and lifetime. A stable owner is the configured workspace namespace plus server account ID; display name and API key are not ownership. No default trusted capability is provided for standalone components.

SurfaceView retains its mounted children across a principal boundary, hides and makes private presentation inert synchronously, stops advisory presence, cancels and revokes owned preview blobs, and fences callbacks. Its descendant gate opens only after fresh unique project/surface/line identity has been checked. A duplicate identity is refused rather than selecting an arbitrary recovery candidate. LineEditor receives the actual surface ID. Root owns its durable text recovery and proposal boundaries.

GeometryEditor retains original raw-source display metadata, draft polygons, undo history, order snapshots and complete unconfirmed submission packets in the mounted instance. Suspension closes a partial gesture without posting it. Late replies cannot acknowledge an earlier owner or erase a newer draft. Forced scope replacement quarantines retained work. Structural mutations are blocked while the current line has text/proposal work; geometry movement and ordering may coexist with text drafts. Unconfirmed structural work cannot be blindly retried. Authoritative fresh reads, rather than an offline cache, are required before resolving uncertainty or discarding. This does not establish durable geometry recovery after browser reload or arbitrary parent destruction.

Session, fragment, dual-pane, health, member, session-admin and registry panels use the same capability and captured HTTP facade. Administrative requests require fresh Admin authority; Reader surface presentation does not start an editing session. Rejected native form events restore their bound values. Missing or inactive capabilities prohibit actions and dispatch.
