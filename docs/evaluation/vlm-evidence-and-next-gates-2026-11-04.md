# VLM benchmark evidence and next gates

The completed experiments establish how specific local model packages, prompts and image preparations behaved on generated controls. The diverse-blank follow-up checks empty-output behavior across six generated backgrounds and keeps matched readable positives in the denominator. Manuscript evaluation depends on the reviewed corpus and comparator.

| Question | Closed evidence | Boundary for the next test |
| --- | --- | --- |
| Can JSON improve blank behavior without damaging transcription? | On the compact set, Qwen3 and Mistral each produced 50/50 valid JSON responses and passed both blank slots under the JSON profile. Plain text passed neither slot. Both-exact pair counts stayed at 6/24 and 2/24 respectively. | The two blank slots repeated one raster, and the profiles changed both prompt and format. Test multiple independently generated blank backgrounds with matched readable positives. Report profile effects as such. An isolated format claim would need identical prompts across conditions. [CLI comparison](vlm-cli-format-compact-2026-11-04.md). |
| Does a supplied OCR string create unsupported output? | All three models emitted text on all six assisted blank requests per model. Mistral copied the hint exactly on 3/6. Opposing hints on 12 locally erased glyph stimuli yielded identical outputs in all 36 matched pairs. The masked diagnostic found 31 anchor mismatches among 108 outputs, with neither proposed glyph inserted between exact anchors after whitespace removal. | Keep full blanks and localized erasures separate. A changed anchor leaves the focal residual unscorable and remains a whole-line error. Include real visible traces adjudicated as unreadable before testing the uncertainty-marker policy on manuscripts. [Crossed hints](vlm-crossed-grounding-2026-11-04.md) · [Masked focal](vlm-masked-focal-2026-11-04.md). |
| What does geometry change? | On the traced line, raw/padded/scaled image token counts were 106/848/424 for Qwen3, 122/1098/605 for Qwen2.5 and 123/1002/609 for Mistral. On compact glyphs, Qwen3 and Qwen2.5 improved focal recovery even among slots whose surrounding characters matched under both layouts after whitespace removal. | The trace measures one fixture. The layout comparison also changed visual gaps and two prefix rasters, so it cannot isolate a padding rule. Freeze crop bounds and compare geometry only on reviewed development images before any selection run. Keep exact spacing in the primary score. [Debug trace](vlm-09-debug-trace-2026-11-04.md) · [Glyph study](vlm-glyph-contrast-2026-11-04.md). |
| Is an empty final answer a recognition failure or a configuration failure? | Gemma reached the token cap without final text on all 96 compact text slots under the CLI configuration. On the native route, reasoning off produced a final message on 3/3 matched probe images versus 0/3 with default reasoning. It then produced final text on all 100 compact slots with reasoning off. | Pin endpoint, reasoning setting and output cap together. Keep HTTP status, final-message availability, schema validity and text accuracy separate. The native and CLI results describe distinct operating configurations. [Reasoning comparison](vlm-native-reasoning-2026-11-04.md). |
| Are outputs reproducible over worker restarts? | Qwen3 and Mistral retained byte-identical final text per fixture across four worker visits and their repeat batches. All 80 slots completed, with exact text on 16/32 text slots per model. | The five images include one blank. Keep repeats and workers separate from independent image counts. Use elapsed timings descriptively because cache history and host activity were uncontrolled. [Reload study](vlm-reload-stability-2026-11-04.md). |

## Four-hour follow-up

| Engineering question | Observed tradeoff |
| --- | --- |
| Does the JSON profile generalize beyond one blank raster? | Qwen3 and Mistral each passed all 24 repeated blank slots across 12 unique rasters. Each returned 12 exact readings on 24 matched readable slots. Mistral's plain profile returned 14 exact readings and passed 12 blank slots. This profile-level result includes the prompt change. [Diverse blanks](vlm-diverse-blanks-2026-11-04.md). |
| Should contrast stretch be a default? | Flat faint inputs benefited Mistral, while Qwen3's gain in exact lines came with more edits. On texture, image-wise stretch recovered two Mistral exact readings and lost two Qwen3 exact readings. Pair-shared stretching also introduced truncated prose on two Qwen3 blanks. Keep contrast settings as explicit candidates. [Flat contrast](vlm-flat-contrast-2026-11-04.md) · [Textured contrast](vlm-textured-contrast-2026-11-04.md). |
| Can script checks or agreement act as acceptance gates? | Script checks caught 30 of 126 glyph errors. In the earlier three-model replay, 40 of 78 quorum-two agreements and six of 20 unanimous agreements were wrong. Both signals can be recorded for review alongside the raw output and visible evidence. [Greek profile triage](vlm-greek-profile-triage-2026-11-04.md) · [Four-hour handoff](../handoffs/vlm-four-hour-2026-11-04.md). |

## Decision sequence

1. **Freeze a finite engineering screen.** Record image hashes, source stimulus families, exact prompts, output profile, decoding, endpoint, package and projector hashes. Rotate paired condition order and keep a planned-slot ledger. For each configuration, report successful empty output per unique blank and per family, and exact text plus scalar edits on paired readable positives. Separately report invalid schema, truncation, missing output and failed transport. An all-empty configuration cannot pass the positive controls. Register any threshold before inspecting output.
2. **Require actual VLM-04 release evidence.** Intake of a returned worksheet verifies identity and protected fields. A qualified reviewer still supplies visible Greek readings, uncertainty, exclusions and crop decisions. The existing P46 release contains 51 provisional crops and zero reviewed selection or confirmation lines. Set physical-unit splits and exposure rules before comparing conditions. Classical Greek needs a separate eligible release and matched R0. [Reviewed-run preflight](vlm-reviewed-run-preflight.md) · [Corpus evidence](../data/vlm-benchmark-corpus.md).
3. **Run VLM-06 only after the release and comparator are frozen.** Compare R0, image-only and image-plus-R0 on the same eligible crops and full planned denominators. Apply the registered per-material CER, completion, mark fidelity, grounding, correction-effort and resource rules. Use human adjudication for suspected unsupported restorations. An insufficient material or physical-unit count yields an inconclusive result. [Benchmark decision criteria](vlm-lmstudio-benchmark.md#evaluation-and-decision-criteria).
4. **Reserve independent confirmation.** If selection yields an eligible condition, freeze it before the custodian releases confirmation inputs. Keep natural performance claims scoped to the reviewed material and comparator. The synthetic screen supplies engineering evidence for this workflow. [Benchmark data splits](vlm-lmstudio-benchmark.md#data-review-and-exposure).
