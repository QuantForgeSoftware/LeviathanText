## Registered matrix and comparison contract

- Preserve PNG/JPEG/GIF/BMP/WebP primary paths and PBM/TGA/TIFF/QOI demonstrated fallback paths. Common primary JPEG remains exact against unchanged primary Skia. No tolerance covers fax inversion/channel swaps. A failed threshold stays failed; do not enlarge it after observing candidate output.
- Compare Decode, Dimensions, DecodeBounded at positive pixel budgets1/128/large, and DecodeBand at full/middle/last/negative-clamped ranges against the actual baseline. Distinguish returned output bounds from temporary full-frame allocation. Existing first-page/source-checksum semantics remain explicit. Invalid budget/argument changes require separate documented owner approval, not an accidental compatibility rewrite.

## Process/resource registration

Each initial functional/negative case runs in its own owned process, sequentially, with a15-second wall deadline,10-second CPU budget,512-MiB observed RSS ceiling, bounded64-KiB stdout/stderr capture, and a `finally` that terminates/reaps only the owned process group. The controller records exit/signal, sampled RSS, managed allocation counters, exact source/runtime/native hashes and operation results. A watchdog kill is a failed resource observation, not a typed rejection or a success. Sampling can miss short peaks and is not a hard OS memory sandbox; no hard universal RSS guarantee is claimed. No untrusted corpus, API bomb, or real decoder service is used.

Before resource timing, register a separate ABBA workload with baseline/candidate sources/binaries fixed and exact output checks, cold startup separated from repeated steady operations. Use generated representative sources only; fix iteration counts and budgets before measurement. Report managed allocations and OS/native RSS separately, retain negative results, and do not add arbitrary timing assertions to unit tests. Broader RIDs require separate runs. Large valid TIFF/metadata budgets, cancellation/exception cleanup, and full-frame fallback have explicit review ownership even if tiny functional cases all pass.
