## Read-only review

The original native model and integrity checks do not enforce capture Frame.ImageRef alias identity. Rejecting conflicting/unverified shared aliases is therefore necessary at delivery lookup; Capture.Id must not be assumed equal to Frame.ImageRef. Production now checks these claims without reading other captures.

The final backend additionally refuses non-PNG/JPEG signatures before constructing a codec. Bounded source/header checks precede bitmap allocation. EXIF orientation is deliberately ignored. The singleton admission lease transfers to response execution and is released on success/failure/cancellation; owned test wrappers dispose a returned result if a held continuation throws. Current credentials, enabled role, membership, local-mode admission, and selected capture record are rechecked after rendering before output. These are finite request-boundary checks, not a promise to retract bytes already delivered if access changes later.

Limits: synchronous native decoding has cancellation checks around it, not a hard native timeout. The 30-second delivery timeout does not prove a universal native/RSS bound. No remote proxy or TIFF route, cross-platform behavior, or all-browser claim is made.
