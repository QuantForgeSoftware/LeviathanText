## What it is

CRNN + CTC line recognizer trained from scratch in C#/TorchSharp on P01 Zenon papyri
(Transkribus-prepared diplomatic labels, **not expert-adjudicated**). Recognition assumes
imported PAGE line geometry; it is not an automatic-layout system.

## Intended use and limits

- Suitable as a **review-assist baseline** on material resembling this documentary hand;
  not suitable for unattended scholarly transcription.
- Labels are not adjudicated; one hand only; no manuscript or inscription coverage.
- The P01 locked split is spent (three uses). This card authorizes **no** new evaluation;
  a release claim needs fresh held-out witnesses and specialist sign-off.
- Confidence is a raw model probability and is not calibrated enough to display as
  certainty.
- The package is reproducible from the recorded config/split/label hashes, but exact
  bitwise weights vary slightly between runs on this CPU backend.
