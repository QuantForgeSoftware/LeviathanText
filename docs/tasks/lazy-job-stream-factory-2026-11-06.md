# PERF-UI-01: isolated native-import stream factory proposal

The Angular idle-panel candidate is rejected: only698 initial bytes removed,11424 total bytes added, and its primary budget goal failed. Do not expand that candidate or change the500000-byte warning budget.

Root proposes a separate isolated candidate using native dynamic import of the pure header-stream module when Watch is first requested. Keep the jobs panel, all workspace/editor/auth views and existing synchronous TEST factory override eager. Do not introduce Angular deferred-view runtime, a fake stream proxy or duplicate the parser/transport's callback/reader lifetime. Load only a code factory, then synchronously create/attach the real stream so its queued start sees the current source identity.

A pending code load owns one finite45-second timer and a cancellable delivery scope. Watch replacement, credential/authority boundary and destroy cancel that scope/timer; the native code download itself is browser-managed and contains no credential. Before invoking the loaded factory, recheck exact watch generation, selected job and captured credential/authority. A late/rejected/timed-out load must not open private HTTP, update another owner's state or revive a destroyed panel. Cache only the loaded code function, never a key or recovery packet. Existing bounded stream/header/retry/callback/body cleanup remains in the real module.

First compare isolated current-source production builds with unchanged budgets and exact initial/total asset sizes. Require initial<=500000 bytes before investing in further behavior gates. If that primary goal fails, retain the negative result and leave main unchanged. No performance/latency inference follows solely from code-byte movement; later loaded code adds a same-origin chunk request on first Watch.

If size passes, add public component/loader controls for immediate synchronous test override, deferred completion, replaced Watch, current/silent credential changes, authority invalidation, destroy, load rejection/timeout/late resolution and no private call before a current code factory is attached. Preserve the original job presentation assertions and all independent stream semantics. Require the whole Angular suite/build, independent review and a newly registered actual browser/API header-stream proof before adoption/closure. No model, training, provider, source text or server authorization change.
