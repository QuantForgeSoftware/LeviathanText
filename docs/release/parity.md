The [305-test inventory](../quality/kraken-test-parity.md) is a frozen reference scenario
list, not a count of passed native tests. Dated suite counts and pilot measurements above
refer to their individual snapshots. This reconciliation reads existing evidence and
does not rerun training or convert provisional labels into accepted data.

**Verdict:** a bounded Greek-transcription pilot with tested engineering workflows.
Drop-in replacement, scholarly acceptance and release readiness remain unestablished.
Adjudicated image-aligned labels, fresh independent witnesses, item-level rights and
cross-platform deployment evidence remain release gates.
