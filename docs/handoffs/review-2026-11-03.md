### 2. Migrated projects bypass the new concurrency check

### 5. Registry pulls can write outside the configured model directory

The new pull endpoint forwards the remote entry's ID to the existing downloader, which uses it in `Path.Combine(modelRoot, entry.Id)`. Registry parsing validates uniqueness and nonemptiness but accepts an absolute filesystem path as an ID. An absolute ID replaces the configured root. Validate IDs as safe single path components and verify the canonical destination is inside the configured root before creating it. ### 6. Automatic redirects bypass the registry host allow-list

The new endpoint checks the initial index URI, then uses a default factory `HttpClient` that follows redirects. Redirect destinations receive no trust-policy validation. ### 7. Inline TEI markup removes surrounding word spaces
